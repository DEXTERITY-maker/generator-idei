# Генератор идей

120 идей с юмором: свидание, уборка, подарок, отдых, семья, работа, путешествия.

Сайт: https://dexterity-maker.github.io/generator-idei/

## Что умеет

- 🎲 Идеи не повторяются, пока не покажутся все в категории (прогресс — на карточке).
- 🔗 У каждой идеи своя ссылка: `…/#idea-17` — «Поделиться» отправляет именно её.
- 📚 «Все идеи» — список с поиском по началу слов (ё = е, слова в любом порядке); клавиша `/`.
- ⭐ Избранное с кнопкой «Вернуть» после удаления и выгрузкой в `favorites.txt`.
- 👆 Свайп по карточке — новая идея; на компьютере — клавиши Пробел, C, F, D.
- 📲 Ставится на телефон как приложение и работает без интернета.
- 🌙 Тёмная тема, 🕓 недавние, счётчик сгенерированных идей.

## Файлы

- `index.html` — весь сайт: разметка, стили, скрипт и 120 идей. Без библиотек и сборки.
- `sw.js` — работа без интернета (страница — из сети, но не дольше 3 с; иконки — из кэша).
  При изменении иконок или манифеста поднять `CACHE` (`idei-v1` → `idei-v2`).
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — установка на телефон.
- `og.png` — картинка для превью ссылки в мессенджерах.

Всё хранится только в браузере (localStorage): `fav_ideas`, `seen_ideas`, `gen_count`, `theme`.
